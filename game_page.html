Règles du jeu

Configuration

2 rangées de 7 cases, 5 graines par case (70 en tout). Sud joue en premier.

Déroulement

Choisissez une case non vide. Les graines sont semées une par une vers la gauche, en passant ensuite dans le camp adverse.

Règle du grenier (>13 graines)

  • Phase 1 : tour complet sans repasser sur la source
  • Phase 2 : le reste tombe uniquement dans le camp adverse

Captures

Si la dernière graine tombe dans le camp adverse sur une case contenant 2, 3 ou 4 graines → capture. La chaîne remonte si les cases précédentes valent aussi 2–4.

⚠ Interdit de vider entièrement le camp adverse.

Case maître

La première case de chaque camp (marquée d'un bouclier) ne peut jamais être capturée lors d'une prise normale.

Solidarité

Camp adverse vide : vous devez lui envoyer des graines. Sinon la partie s'arrête.

Fin de partie

  • Un joueur atteint 40 graines capturées → victoire
  • Moins de 10 graines sur le plateau → fin
  • Aucun coup légal disponible → fin

Dans les deux derniers cas, chaque joueur récupère les graines de son camp.

Historique des coups

Aucun coup joué.
